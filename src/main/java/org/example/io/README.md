## Модуль 1.4. Java Core — ввод-вывод

### Результат замеров

- Размер файла 50МБ
- Размер буфера 8КБ
- Копирование без буфера 196765 мс
- Копирование с буфером 1378 мс
- Копирование с буфером быстрее в 142.7 раз

---

### Вывод

Существенную роль играет количество "дорогих" системных вызовов,
при которых происходит переключение контекста процессора. Использование буфера 
позволяет на порядки уменьшить количество системных вызовов.
